# Query Explorer & Analytics + 5-Mode Operation Switcher (`v1.8.0`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver `v1.8.0` with (1) upgraded `Live Monitor` → `Query Explorer & Analytics` (5,000-entry buffer, per-domain session aggregator, enriched DNS metadata, 1-click inspector actions, spam detector, CSV export) and (2) seamless 5-mode switcher bar beneath the 5 Dashboard gauges (`HighSpeed`, `Gaming`, `Balanced`, `Auto`, `Security`) with sliding & pulsing animations, baseline snapshot restoration, Auto-mode real-time adaptation, and per-mode customization.

**Architecture:** Pure domain models, Schema v19 configuration, CSV sanitizer, and Auto-mode hysteresis evaluator live in `JustCryptDns.Core`; live query capture and bounded per-domain aggregation live in `JustCryptDns.DNS` + `JustCryptDns.Network`; incremental Named Pipe IPC sync lives in `JustCryptDns.Service`; UI orchestration (`OperationModeService`), the seamless 5-switch control (`OperationModeSwitcherControl`), Dashboard integration, and upgraded `LiveMonitorView` live in `JustCryptDns.App`.

**Tech Stack:** .NET 8 (`net8.0-windows`), WPF, CommunityToolkit.Mvvm, xUnit, Win32 Shell/User32 P/Invoke (`SHQueryUserNotificationState`, `GetForegroundWindow`).

## Global Constraints
- `dotnet build JustCryptDns.sln -c Release` MUST finish with `0 Warning(s), 0 Error(s)`.
- `dotnet test JustCryptDns.sln -c Release` MUST pass 100% (`Failed: 0`), including `LocalizationResourceTests`, `ViewInstantiationSmokeTests`, `BackgroundOperationTests`, `BypassAllWebPhase14Tests`.
- Switching modes MUST NEVER delete or alter `Filtering.CustomBlockedDomains`, `Filtering.Allowlist`, `Routing.Rules`, `Routing.LocalRewrites`, `Bypass.Rules`, `Connections.BlockedRules`, or `Connections.BlockedApps`.
- All new UI copy MUST exist in both `Strings.en.resx` and `Strings.vi.resx`.
- Never kill or stop any running `JustCryptDns.exe`, `JustCryptDnsService`, or `dnscrypt-proxy.exe` processes.

## Review Focus
- IPC frame overflow when fetching up to 5,000 live queries over Named Pipe → covered by `SequenceId` incremental delta queries + 2 MB `MaxMessageBytes` cap.
- Unbounded RAM growth in per-domain session aggregator during days-long uptime → covered by `4,096` domain cap with low-count/oldest eviction test.
- Auto-mode flapping on brief Alt-Tab out of fullscreen games → covered by `CooldownSeconds` (default 20s) hysteresis test in `OperationModeEvaluator`.
- Restoring user visual & baseline settings after leaving `Gaming` or `HighSpeed` mode → covered by `OperationBaselineSnapshot` round-trip test.
- Spreadsheet CSV formula injection when exporting untrusted domain names or DNS TXT/answer summaries → covered by `CsvExportHelper` sanitization test.
